Privacy Policy — VAHAN RPA Assistant

Last updated: September 15, 2026

VAHAN RPA Assistant helps users fill report filters on the VAHAN Public Report website and initiate Excel export after the user manually completes the CAPTCHA.

Data handled

The extension reads dropdown options and report-form fields only on analytics.parivahan.gov.in. It stores the user's selected report-filter preferences locally through chrome.storage.local.

Data not collected

The extension does not collect or store CAPTCHA values, authentication credentials, personal information, browsing history, analytics, or advertising identifiers. It does not transmit user data to the developer or to a developer-controlled server.

External requests

Requests for RTO and vehicle-maker options are sent directly to the VAHAN website over HTTPS and use the user's existing VAHAN browser session. The extension does not send those responses elsewhere.

Sharing and sale

No user data is sold, shared with third parties, used for advertising, or used for credit-related purposes.

Retention and deletion

Filter preferences remain in the user's local Chrome profile until they are overwritten, cleared from extension storage, or the extension is uninstalled.

Limited Use

The use of information received through Chrome APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.
