# Publishing checklist

- Replace `REPLACE_WITH_SUPPORT_EMAIL` in `privacy-policy.html`.
- Publish `privacy-policy.html` at a public HTTPS URL and enter it in the Dashboard Privacy tab.
- Add the support/homepage URLs in `store-listing.md`.
- Capture at least one screenshot of the real popup and one of VAHAN after filters are filled.
- Obtain approval to use the VAHAN name and to distribute the automation.
- Test from a clean Chrome profile.
- Create the upload ZIP with `pack-extension.ps1`.
- Upload the ZIP in the Chrome Web Store Developer Dashboard.
- Complete Store Listing, Privacy, Distribution, and Test instructions.
